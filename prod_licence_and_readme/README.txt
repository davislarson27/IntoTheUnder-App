HOW TO RUN:

1. Move Into The Under into the applications folder.
2. Click the game.
3. Pin to the dock.


----------------------------------------------------------------------

Apple Gatekeeper Warning

----------------------------------------------------------------------

Because this app is independently made and not distributed through
the Mac App Store, Gatekeeper may block it from opening the first time.

To get past this:
1. Right-click (or Control-click) the app icon
2. Select "Open" from the menu
3. Click "Open" in the dialog that appears

You only need to do this once — after that it opens normally.


----------------------------------------------------------------------

Controls:

W / A / S / D / SPACE - Move
E - Open Inventory
C - See Available Recipes
F - Open the Refuel and Repair Menu
Left Click - Mine
Right Click - Place Blocks / Interact With Blocks
Scroll / Enter to switch Inventory Position
Caps Lock - If on, allows placing and mining background blocks
Left Shift - Stop block interactions
F3 - Debug Overlay (Coordinates)
ESC - Exit and Save Game
